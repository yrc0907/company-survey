# 公开文件预览

项目详情的文件树点击后统一经过 `projectFileView` 投影。公开主版本只返回公开 Revision 或 `source` 表中 `active` 来源的最小预览，不把私有 OSS object key、上传凭据或草稿内容发给浏览器。

## 类型与边界

- Markdown/TXT：正文按来源快照的原文段落展示；不会把文件名或项目摘要当作正文。
- PDF：展示格式、采集时间、哈希和可用的文本解析结果；没有解析产物时明确显示待解析状态，可打开公开来源 URL。
- 图片：仅当来源提供明确的 HTTP(S) 地址时展示图片，使用 `no-referrer`；私有原件不会生成公开地址。
- CSV/XLSX：存在解析产物行列时显示表格；只有原件元数据时显示“暂无解析结果”，不猜测单元格。
- 无法识别或缺少原件：显示可解释空状态，保持 `needs_verification`，不生成内容。

Repository 会按 `report-{projectId 去掉 project- 前缀}`关联历史来源，并按文件名兜底；读取仅限 `state = active`，快照最多返回 40,000 字符。后续上传文件必须经过私有 OSS 校验和解析 Worker，再由公开版本合并后才可进入该投影。

## 当前可以确认已经交付的能力

这些能力有代码或验收记录支撑，可以作为当前版本的真实范围：

1. **公开阅读与检索**：首页项目列表、公开项目详情、全站搜索、来源 URL 和文件树投影；AI 助手仅向登录后的内测用户开放。
2. **五家独立研究项目文档**：慧策掌上先机、泛微网络、深信服、信锐科技、牧原食品。每家单独维护产品、客户/场景、商业模式、竞争、政策、风险、Yu 的判断和证据状态，不做默认总排名；此前按用户要求清空了服务器公开项目数据，当前报告以仓库文档保存，未自动恢复到公开数据库。
3. **证据和关系图**：PostgreSQL FTS、可选 Dense RRF、Reranker 降级、Parent Retrieval、GraphRAG-lite 有界 BFS、来源回溯和 `fact/inference/needs_verification/conflict` 边界。
4. **研究数据展示**：泛微、深信服、牧原的公开行情/财报数据卡和持久化日线曲线；缺失数据仍显示待核验，不用静态数字补齐。
5. **协作只读投影**：公开版本历史、逐 Commit Diff、owner-only HEAD 回滚、评论/回复、点赞、Star、关注、作者主页、活动热力图和通知 API 的基础能力；历史社区 synthetic 账号已退役。
6. **文件安全投影**：Markdown、TXT、PDF、图片、CSV、XLSX 预览；私有 OSS 原件隔离，原件与可编辑派生正文分开。
7. **内测认证关闭模式**：`PUBLIC_AUTH_ENABLED=false` 时登录、注册、上传等入口明确提示“登录功能暂未开放，仅对内测用户开放”，认证 API 返回 `403 AUTH_CLOSED`。
8. **部署基线**：香港 ECS、Docker Compose、PostgreSQL 命名卷、Caddy HTTPS、`/healthz` 和公网平台 E2E 记录已具备。

- 增加磁盘、容器、备份、证书和公网可用性告警，记录恢复点和恢复耗时。

### P1：身份、上传和协作闭环

- 认证保持关闭是当前产品决策，不代表真实邮箱/短信/图形验证已完成正向公网回归；开启前要用测试账号验证注册、验证码登录、找回密码、换绑、限流和审计。

- 三方冲突展示、审核/合并后的署名回放仍需补齐；公开逐段 Diff 与 owner-only 当前 HEAD 反向回滚 API/UI 已上线。
- 接通评论回复、MR 审核/合并、关注更新的通知深链；补举报、许可证、下架审计和头像 WebP 派生。

### P2：来源、检索和记忆规模化

- 把安全 URL 来源刷新接入 HTTP 路由和定时任务，保存变化检测、哈希和 `needs_review` 版本。
- 在 pgvector 可用环境完成 ANN 索引重建 Worker、批量调度和真实 Golden Set 指标采集；当前检索可用但不是规模化生产闭环。
- 补齐会话 Resume、自动压缩触发、历史对话完整投影、记忆删除清理和 pgvector 持久化；当前结构化记忆/压缩契约已存在。
- 原生联网搜索和视觉输入仍需 Job、路由、来源落库与失败回归，不能把 Provider 可调用误写成用户功能已完成。

### P3：研究内容深度

- 五家公司继续补独立年报、公告、访谈和竞品证据。
- 分产品收入/利润、完整年报指标、竞品定量数据和时间线仅在有公开来源时补入；没有来源的字段保持空值或 `needs_verification`。
- 扩展产品、上下游和政策关系边，但关系写入必须走草稿、审核和合并，不能由公开只读图直接写入事实。

## 真实数据和安全边界

- 页面上的用户、评论、阅读、Star、关注和贡献只能来自真实注册账号或有明确来源的持久化记录；禁止重新创建 `community-user-*` 假账号，禁止用静态数字证明市场热度。
- 生产密钥、邮箱授权码、短信/图形验证密钥、RAM 凭据和数据库密码只放服务器环境变量或临时凭据，不写入 Git、文档、日志和客户端 Bundle。此前在聊天中暴露过的密钥应轮换。
- 企业事实必须带来源 URL、抓取时间、片段位置、哈希和证据状态。模型只能总结、抽取和起草，不能替代来源或自动合并。
- 认证关闭期间，匿名用户可以阅读公开内容；AI、写入、上传、创建、编辑或申请贡献均返回登录门槛。认证开启后，AI 仍必须绑定真实 Session。

## 建议的关闭顺序

1. 先完成 P0 安全组、异机备份/恢复和告警，形成可恢复生产基线。
2. 再开启一个内测账号，完成认证、OSS 直传、上传解析、Diff/MR/合并和通知深链的真实回归。
3. 然后接来源刷新、视觉解析、pgvector ANN 和会话记忆规模化能力。
4. 最后补五家企业的独立证据深度和定量研究字段。

## 可重复验收命令

在仓库根目录运行：

```bash
pnpm typecheck
pnpm lint
pnpm test
pnpm build
pnpm test:e2e:platform
```

公网验收前设置：

```powershell
$env:PLATFORM_BASE_URL='https://research.webyrc.com'
pnpm test:e2e:platform
```

验收记录、部署证据和历史故障不要只改本文件，应同时追加到 [前后端性能与交互验收记录](performance-and-e2e-verification.md) 和 [问题与性能记录](problem-solution-performance.md)。
